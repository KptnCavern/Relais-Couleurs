RELAIS COULEURS - V1.1 - POUR GITHUB PAGES SUR SOUS-DOMAINE

URL attendue : https://relais-couleurs.kptncorp.fr/

1. Uploadez les fichiers de CE ZIP a la racine du depot publie par GitHub Pages (index.html, style.css, assets/, fr/, en/).
2. Dans GitHub > Settings > Pages > Custom domain, renseignez relais-couleurs.kptncorp.fr.
3. Chez OVH : CNAME relais-couleurs -> VOTRE-PSEUDO.github.io.
4. Activez Enforce HTTPS une fois le certificat cree.
5. Testez ces URLs :
   https://relais-couleurs.kptncorp.fr/fr/
   https://relais-couleurs.kptncorp.fr/style.css
   https://relais-couleurs.kptncorp.fr/assets/shirori.webp
   https://relais-couleurs.kptncorp.fr/app-ads.txt
6. Google Play : site du developpeur = https://relais-couleurs.kptncorp.fr/ ; politique = https://relais-couleurs.kptncorp.fr/fr/confidentialite.html
7. Le fichier app-ads.txt doit afficher une ligne de texte brut et etre accessible sur le domaine annonce dans Google Play.

ATTENTION : Confidentialite FR et EN encore a relire/completer avec votre identite d'editeur et les SDK reellement deployes.
Si vous utilisez un domaine principal ou un chemin /relais-couleurs/ au lieu de ce sous-domaine, adaptez les URLs.
